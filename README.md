# Game Optimizer

Оптимизация Windows-ПК под игры из Steam в один клик. Приоритет: **максимум FPS**.

## Скачать

Страница **Releases** справа: скачай `GameOptimizer.exe` и запусти (попросит права администратора).
Сверить файл можно по `GameOptimizer.exe.sha256`.

> Windows SmartScreen может показать «Неопознанный издатель»: нажми «Подробнее» → «Выполнить в любом случае». Код программы открыт, exe собирается автоматически из этого репозитория (GitHub Actions).

## Что делает

1. **Видеокарта.** Определяет NVIDIA или AMD.
   - NVIDIA: глобальный профиль драйвера (режим питания = максимальная производительность, V-Sync выкл) через официальный NVIDIA Profile Inspector, который скачивается с GitHub.
   - AMD: ключи драйвера в реестре (отключение ULPS, V-Sync выкл). **Экспериментально, не проверено на реальных картах AMD.**
2. **Система.** Схема питания Ultimate Performance, Игровой режим, отключение Game DVR, аппаратное планирование GPU, приоритет игр в планировщике, отключение ускорения мыши, снижение сетевой задержки, очистка TEMP.
3. **Игры Steam.** Находит установленные игры во всех библиотеках. Для каждой: запуск на дискретной видеокарте, приоритет процесса High, без оптимизаций полного экрана.
   Отдельные профили (параметры запуска, конфиги, видеонастройки) сейчас есть для **CS2, Dota 2, Apex Legends**. Остальные получают общие настройки.

## Безопасность

- Перед работой создаётся точка восстановления Windows.
- Каждое изменение (реестр, файлы, схема питания, профиль NVIDIA) записывается в журнал `%APPDATA%\GameOptimizer\journal.json`. Кнопка **«Откатить всё»** возвращает прежнее состояние. Исключение: очистка TEMP.
- Параметры запуска Steam пишутся, только когда Steam закрыт; существующие флаги не перезаписываются.
- Откат профиля NVIDIA возвращает режим питания «Адаптивный» и V-Sync «по настройке приложения».

## Командная строка

```
GameOptimizer.exe --list                  # видеокарта и игры
GameOptimizer.exe --apply-all --dry-run   # показать, что будет сделано, ничего не меняя
GameOptimizer.exe --apply-all
GameOptimizer.exe --revert
```

## Добавить игру

В `optimizer/games.py` допиши `Profile` в словарь `PROFILES` (ключ: appid игры в Steam).

## Сборка

```
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --noconsole --uac-admin --icon assets/icon.ico --name GameOptimizer main.py
```

Релиз: exe собирается командой выше и прикладывается к GitHub Release. Workflow для автосборки лежит в `ci/release.yml` (чтобы включить, перенеси его в `.github/workflows/`).
